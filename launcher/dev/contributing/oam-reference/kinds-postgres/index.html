    • TestCnpgPublication_TargetAsWritten shows the first for each of the four, and the second for the three that can stand alone (an empty columns alone is a table that lists none). [“The first” is the case in which the API server refuses the document as authored and accepts the object the build writes, “the second” is the case in which the API server accepts the document as authored and the build refuses it, “the four” are allTables: false and an empty objects, tablesInSchema or columns, which the reference page gives, and the test is in cnpg_further_kinds_internal_test.go.]
    • TestCnpgFurtherKinds_ExpressionRules lists all 26 with what is done with each, and fails on a rule that is added, dropped or reworded. [“All 26” are the 26 expression rules of the seven CRDs, which the reference page counts, and the test is in cnpg_further_kinds_internal_test.go.]
    • It holds each of the 15 to the API server’s own expression validator, run over the linked CRD after the defaults the API server fills: with every other rule set aside, the validator refuses the properties that break the rule, and with every rule it accepts the ones next to them and the object the build writes for them; the build answers the same on both. [“It” is TestCnpgFurtherKinds_ExpressionRules, which the previous entry names, “the 15” are the 15 rules that read one document, which the reference page names, and the test is in cnpg_further_kinds_internal_test.go.]
    • TestImageTagRule_CnpgImageCatalogs holds the three, on both kinds. [“The three” are the three fields of a catalog that name an image, which the reference page gives, “both kinds” are cnpg-imagecatalog and cnpg-clusterimagecatalog, and the test is in image_tag_rule_test.go.]
    • TestCnpgImageCatalogs_ImagesAreHeldToTheAllowedRegistries holds the three, on both kinds. [“The three” are the three fields of a catalog that name an image, which the reference page gives, “both kinds” are cnpg-imagecatalog and cnpg-clusterimagecatalog, and the test is in cnpg_further_kinds_test.go.]
