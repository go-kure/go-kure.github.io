Releases

Changelog

All notable changes to this project will be documented in this file.

Builder contract, release 1. The builder contract (ADR-038, “thin core plus admissible sugar”) removes several hundred Create*/Set*/Add* helpers and every value the constructors used to inject. Every removal is listed once, with the expression that replaces it, in Builder contract: release 1 migration notes : the deleted helpers and sub-type constructors, and the constructor and workflow defaults that no longer apply. Read it before upgrading across the entries below. The contract itself is Kubernetes Builders .

Builder contract, release 2. The Kind(&Config) layer — one function per kind taking a kure-invented Config struct — is retired in certmanager, cnpg, externalsecrets, prometheus, cilium and volsync, together with the sealed IssuerVariant, ACMESolver, DNS01Provider, SourceMover and DestinationMover sums and the values that layer injected. Every removed function, type and field is mapped to the upstream field that replaces it in Builder contract: release 2 migration notes .
